# 💬 익명 피드백 서비스

> 팀원 간 솔직한 의견을 익명으로 주고받을 수 있는 웹 기반 피드백 서비스

개인별 피드백 페이지를 생성하고, 발급된 **6자리 코드**를 팀원에게 공유하면  
다른 사용자가 해당 페이지를 찾아 **장점과 개선점**을 익명으로 작성할 수 있습니다.

페이지 소유자는 **4자리 PIN 인증** 후 본인에게 작성된 피드백만 확인할 수 있으며,  
관리자는 전체 페이지와 피드백을 한 번에 관리할 수 있습니다.

---

## ✨ 프로그램 개요

### 🎯 서비스 목적

팀 프로젝트, 교육 과정, 스터디, 조직 내 협업 과정에서  
직접 말하기 어려운 의견을 조금 더 부담 없이 전달할 수 있도록 만든 서비스입니다.

작성자의 이름이나 계정 정보를 따로 받지 않고,  
피드백 대상자만 본인의 PIN을 통해 내용을 확인할 수 있도록 구성했습니다.

### 👥 주요 사용 대상

- 팀 프로젝트 참여자
- 교육 과정 수강생
- 스터디 구성원
- 소규모 조직 및 협업팀
- 동료 피드백이 필요한 프로젝트 구성원

---

## 🚀 주요 기능

### 👤 개인 피드백 페이지 생성

사용자는 아래 정보를 입력해 개인 페이지를 생성할 수 있습니다.

- 이름 또는 닉네임
- 직무 및 역할
- 4자리 PIN

페이지 생성 시 **6자리 고유 코드**가 자동으로 발급됩니다.

해당 코드를 팀원에게 공유해 피드백을 받을 수 있습니다.

---

### ✍️ 익명 피드백 작성

피드백 작성자는 아래 방식으로 대상 페이지를 찾을 수 있습니다.

- 6자리 코드 검색
- 이름 검색

피드백은 아래 두 항목으로 구분됩니다.

- ✅ 장점
- 🔧 단점 및 개선점

각 항목은 최대 **300자**까지 작성할 수 있습니다.

작성자의 이름, 계정 등 별도의 식별 정보는 저장하지 않습니다.

---

### 🔐 PIN 기반 피드백 조회

페이지 소유자는 페이지 생성 시 설정한  
**4자리 PIN을 입력해야 본인의 피드백을 확인할 수 있습니다.**

PIN 인증 후에는 장점과 단점을 구분하여 확인할 수 있습니다.

---

### ⚡ 내 페이지 바로가기

홈 화면에서 본인의 **6자리 페이지 코드**를 입력하면  
바로 PIN 인증 화면으로 이동할 수 있습니다.

내 페이지 목록이 보이지 않더라도  
코드를 알고 있다면 바로 접근할 수 있습니다.

---

### ♻️ 내 페이지 복구

브라우저 변경, 저장 데이터 초기화 등으로  
`내가 만든 페이지` 목록이 사라진 경우에도 복구할 수 있습니다.

복구 시 아래 정보를 입력합니다.

- 6자리 페이지 코드
- 4자리 PIN

인증이 완료되면 해당 페이지가 다시  
`내가 만든 페이지` 목록에 등록됩니다.

---

### 🔔 새 피드백 알림

마지막 확인 이후 새로 등록된 피드백 개수를 자동으로 확인합니다.

새로운 피드백이 존재하면 화면 하단에 다음과 같은 알림이 표시됩니다.

> 👀 N개의 새로운 피드백이 있어요!

피드백을 확인한 시점을 기준으로 새 피드백 개수가 초기화됩니다.

---

## 🛠 관리자 기능

관리자 전용 페이지에서 전체 서비스 상태를 관리할 수 있습니다.

### 📊 전체 현황 확인

관리자 대시보드에서 아래 정보를 확인할 수 있습니다.

- 전체 생성 페이지 수
- 전체 등록 피드백 수
- 생성된 전체 페이지 목록

---

### 🗂 페이지별 피드백 확인

관리자는 생성된 각 페이지에 들어가  
해당 페이지에 작성된 장점과 단점 피드백을 확인할 수 있습니다.

---

### 🗑 개별 피드백 삭제

각 피드백 항목의 삭제 버튼을 통해  
특정 피드백 하나만 개별적으로 삭제할 수 있습니다.

---

### ❌ 페이지 전체 삭제

관리자는 특정 페이지를 전체 삭제할 수 있습니다.

페이지가 삭제되면 해당 페이지에 연결된 피드백도 함께 삭제됩니다.

---

### 🔒 서비스 열림 / 잠금

관리자 페이지에서 서비스 상태를 변경할 수 있습니다.

#### 🟢 OPEN

- 신규 페이지 생성 가능
- 신규 피드백 작성 가능
- 기존 피드백 조회 가능

#### 🔴 CLOSED

- 신규 페이지 생성 차단
- 신규 피드백 작성 차단
- 기존 피드백 조회 가능

---
